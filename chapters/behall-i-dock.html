Högerklicka på Visual Studio Code i Dock.

Så gör du på din Mac

  1. Öppna appen så att dess symbol visas i Dock.
  2. Högerklicka på symbolen. På en styrplatta kan du klicka med två fingrar.
  3. Peka på Alternativ.
  4. Klicka på Behåll i Dock. En bock visar att appen blir kvar när du stänger den.
